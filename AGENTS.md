## LingoBango development

- This is a Vite + React + TypeScript app. Use `npm run dev` for local development.
- Keep UI behavior accessible: preserve keyboard access, visible focus states, and reduced-motion support.
- Run `npm run build` and `npm test` before submitting changes.
- Keep dependencies in `package.json`/`package-lock.json`; do not commit `node_modules/` or build output.
- Prefer small, focused components and CSS variables for visual tokens.
